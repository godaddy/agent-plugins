# agent-plugins

Portable Agent Plugins maintained by GoDaddy.

This repository is being bootstrapped around the vendor-neutral [Agent Plugins
1.0.0 specification](https://agent-plugins.org/specification). The first planned
package is `commerce`, which will combine a Storefront skill, a dedicated
Payments skill, and GoDaddy Commerce's remote MCP server.

See [the implementation plan](docs/commerce-plugin-plan.md) for scope,
package design, delivery phases, and release gates.

> Status: planning. No installable plugin has been released from this repository
> yet.
